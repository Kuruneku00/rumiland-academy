## 🚀 نصب و اجرا (Kali Linux / Debian / Ubuntu)

### روش سریع — یک‌دستور

```bash
bash install.sh
```

این اسکریپت به‌صورت خودکار:
1. Node.js و Git را (در صورت نبود) نصب می‌کند
2. کد را از GitHub بارگیری می‌کند
3. وابستگی‌ها را نصب و برنامه را build می‌کند
4. یک دستور سراسری `rumiland` می‌سازد و برنامه را اجرا می‌کند

### اجرا پس از نصب

```bash
rumiland
```

### روش دستی

```bash
git clone https://github.com/Kuruneku00/rumiland-academy.git
cd rumiland-academy
npm install
npm run build
node scripts/build-electron.mjs
npm start        # یا: npx electron .
```

## 💾 داده‌ها کجا ذخیره می‌شوند؟

داده‌های شما در یک فایل پایدار روی دیسک ذخیره می‌شوند و **هرگز به‌خاطر بستن برنامه یا پاک شدن کش مرورگر از بین نمی‌روند**:

```
~/.rumiland-academy/data.json          ← داده اصلی
~/.rumiland-academy/backups/           ← پشتیبان‌گیری خودکار (۲۰ نسخه اخیر)
```

- **ذخیره خودکار**: بعد از هر تغییر، داده به‌صورت خودکار روی دیسک نوشته می‌شود.
- **بازیابی خودکار**: هنگام باز کردن برنامه، آخرین دادهٔ ذخیره‌شده بارگذاری می‌شود.
- **پشتیبان خودکار**: قبل از هر ذخیره، یک نسخهٔ پشتیبان از نسخهٔ قبلی نگه داشته می‌شود.
- **پشتیبان دستی**: از بخش `تنظیمات ← پشتیبانی و بازبینی` می‌توانید نسخهٔ پشتیبان دانلود یا بازگردانی کنید.

> در نسخهٔ وب (بدون Electron)، داده‌ها به‌صورت موقت در مرورگر (localStorage) نگهداری می‌شوند.

## 📁 ساختار پروژه

```

│   ├── components/         # کامپوننت‌های UI
│   ├── db/                 # اسکیما و seed دیتابیس

│   ├── theme/              # تم و توکن‌های CSS

├── electron/               # فرآیند اصلی Electron (main, preload, ipc)
├── backend/                # (رزرو برای بک‌اند آینده)
├── scripts/                # اسکریپت‌های build
├── install.sh              # نصب‌کننده یک‌دستوری
└── package.json
```

## 🔒 معماری ذخیره‌سازی

```
React (renderer)  →  Dexie (IndexedDB)  →  persistence layer  →  IPC  →  فایل JSON روی دیسک
                                                                          (~/.rumiland-academy/data.json)
```

- در حالت Electron، داده از طریق IPC به فایل JSON روی دیسک منتقل می‌شود.
- در حالت وب، از localStorage به عنوان fallback استفاده می‌شود.
- کل فرآیند خودکار است و کاربر نیاز به کاری ندارد.
